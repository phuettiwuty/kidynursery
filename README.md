# Kindery

เว็บแอปต้นแบบสำหรับติดตามพัฒนาการเด็กปฐมวัย ออกแบบแบบ mobile-first

## ฟีเจอร์หลัก

- รายชื่อผู้ปกครอง นักบริบาลชุมชน (CG) อสม. คณะผู้บริหาร ครู และบุคลากร
- การสื่อสารและประกาศระหว่างศูนย์กับครอบครัว
- ติดตามพัฒนาการแบบ Real Time
- บันทึกสุขภาพ น้ำหนัก ส่วนสูง และแนวโน้มการเจริญเติบโต
- ความรู้และแนวทางการเลี้ยงดูตามช่วงวัย
- รายชื่อเด็กและแผนผังพื้นที่บ้านสำหรับการเยี่ยมบ้าน
- ปฏิทินวัคซีน นัดหมายแพทย์ และวันวัดส่วนสูง/น้ำหนัก
- ตารางมาตรฐานการเจริญเติบโตสำหรับเด็กอายุแรกเกิดถึง 5 ปี

## บัญชีทดลอง

- ผู้ปกครอง: `parent01` / `1234`
