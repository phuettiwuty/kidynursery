# Kindery

เว็บแอปสำหรับติดตามสุขภาพและนัดหมายเด็กปฐมวัย ออกแบบแบบ mobile-first และเชื่อม Google Sheets/Drive ผ่าน Google Apps Script

## ฟีเจอร์หลัก

- รายชื่อเด็ก ผู้ปกครอง ครู และบุคลากร พร้อมภาพจาก Google Drive
- บันทึกและดูประวัติน้ำหนัก–ส่วนสูง
- นัดรับวัคซีน นัดแพทย์ และวันวัดส่วนสูง/น้ำหนักครั้งละหลายคน
- ผู้ปกครองเห็นเฉพาะข้อมูลของบุตรหลานที่ผูกกับบัญชี
- อัปเดตข้อมูลจาก Google Sheets ทุก 30 วินาที

## บัญชีเข้าสู่ระบบ

- ครู: ชื่อผู้ใช้คือ `TEA` ตามด้วยรหัสครู 3 หลัก เช่น `TEA001`
- ผู้ปกครอง: ชื่อผู้ใช้คือ `KID` ตามด้วยเลขประจำตัวเด็ก เช่น `KID12345`
- ทุกบัญชีใช้รหัสผ่านส่วนตัวที่ไม่ซ้ำกัน ความยาว 6–64 ตัวอักษร ห้ามใช้รหัสครูหรือเลขประจำตัวเด็กเป็นรหัสผ่าน

ครูแต่ละคนมีบัญชีของตัวเอง และชื่อครูที่เข้าสู่ระบบจะถูกบันทึกกำกับรายการน้ำหนัก/ส่วนสูงที่เพิ่มเข้ามา ส่วนบัญชีผู้ปกครองแต่ละบัญชีจะเห็นเฉพาะเด็กที่ตรงกับเลขประจำตัวที่ใช้เข้าสู่ระบบ

## หน้าผู้ปกครอง

- ดูรูป ชื่อ เลขประจำตัว วันเกิด ห้องเรียน ความสัมพันธ์ผู้ปกครอง และที่อยู่ของบุตรหลาน
- ดูน้ำหนักและส่วนสูงล่าสุด รวมถึงประวัติย้อนหลังที่คุณครูบันทึก
- ดึงข้อมูลล่าสุดจาก Google Sheets อัตโนมัติทุก 30 วินาที โดยไม่ต้องรีเฟรชหน้า
- ใช้ session ชั่วคราว 1 ชั่วโมงแบบต่ออายุเมื่อมีการใช้งาน และตรวจสิทธิ์ที่ Google Apps Script ก่อนส่งข้อมูลกลับมา

## บันทึกการเจริญเติบโต

คุณครูสามารถบันทึกน้ำหนักและส่วนสูงจากปุ่มบนหน้าภาพรวมหรือจากหน้าต่าง “ดูข้อมูล” ของเด็กแต่ละคน โดยระบุวันที่วัด น้ำหนัก ส่วนสูง และหมายเหตุ ระบบจะยืนยันการบันทึกกับแท็บ `GrowthRecords` ก่อนแสดงผล และไม่เก็บข้อมูลเด็กถาวรไว้ใน Local Storage ของเบราว์เซอร์

## วัคซีนและนัดหมาย

- ครูเพิ่มนัดแพทย์ นัดรับวัคซีน วันวัดน้ำหนัก–ส่วนสูง หรือนัดหมายอื่นได้ พร้อมกำหนดวันแจ้งเตือนล่วงหน้า
- นัดหมายหนึ่งครั้งเลือกเด็กได้หลายคน โดยระบบสร้างสถานะแยกให้เด็กแต่ละคน
- ครูติ๊กว่าเด็กได้รับวัคซีนแล้วหรือดำเนินการนัดหมายเสร็จแล้วเป็นรายคน และยกเลิกการติ๊กเพื่อกลับเป็นสถานะรอนัดได้
- แสดงรายการใกล้ถึงกำหนด เกินกำหนด และรายการที่ดำเนินการเสร็จแล้ว โดยไม่คำนวณตารางวัคซีนอัตโนมัติ
- ผู้ปกครองเห็นเฉพาะนัดรับวัคซีนและนัดหมายอื่นของบุตรหลาน พร้อมสถานะล่าสุดที่คุณครูอัปเดตทุก 30 วินาที
- การแจ้งเตือนเป็นการแจ้งเตือนภายในหน้าเว็บ ยังไม่ใช่ SMS, LINE หรือ Push Notification

## ข้อมูลผู้ปกครองสำหรับครู

เมนู “ผู้ปกครอง” ในหน้าครูแสดงชื่อผู้ปกครอง ความสัมพันธ์ เด็กในความดูแล ห้องเรียน เบอร์โทรศัพท์ และที่อยู่ปัจจุบัน สามารถค้นหาจากชื่อผู้ปกครอง ชื่อเด็ก เบอร์โทร หรือที่อยู่ และกรองตามห้องเรียนได้

## การเชื่อม Google Sheets

โปรเจกต์ตั้งค่า Spreadsheet ID ของไฟล์ `kidnersary` ไว้แล้วใน `config.js` และมีตัวกลางที่ `google-apps-script/Code.gs`

ระบบใช้แท็บฐานข้อมูลเพิ่มเติม 4 แท็บ:

- `ParentAccounts` เก็บชื่อผู้ใช้, รหัสผ่านแบบ SHA-256, ชื่อผู้ปกครอง และเลขประจำตัวเด็กที่ผูกกับบัญชี
- `TeacherAccounts` เก็บบัญชีครูรายบุคคล รหัสผ่านแบบ SHA-256 ชื่อ ตำแหน่ง ห้องเรียน และสถานะการใช้งาน
- `GrowthRecords` เก็บวันที่วัด น้ำหนัก ส่วนสูง หมายเหตุ และเวลาที่บันทึก
- `Appointments` เก็บประเภทนัด วันที่ เวลา สถานที่ สถานะ วันดำเนินการเสร็จ จำนวนวันที่แจ้งเตือนล่วงหน้า และครูผู้บันทึก

ข้อมูลเด็กไม่ถูกส่งจาก API สาธารณะ ผู้ใช้ต้องเข้าสู่ระบบก่อนจึงจะอ่านแท็บต่อไปนี้ได้:

- `Preanuban` → เตรียมอนุบาล 1/1
- `Preanuban2` → เตรียมอนุบาล 1/2
- `Anuban` → อนุบาล 1

รายละเอียดวันเกิด ผู้ปกครอง เบอร์โทร และที่อยู่ถูกอ่านจาก Google Sheets หลังตรวจสิทธิ์เท่านั้น หน้าเว็บไม่โหลด `student-details.js` หรือ `photo-map.js` และไม่นำเลขประจำตัวประชาชนมาใช้

### เปิดใช้งาน

1. เปิดโปรเจกต์ [Google Apps Script](https://script.google.com/) ด้วยบัญชีที่เปิด Spreadsheet นี้ได้
2. วางโค้ดจาก `google-apps-script/Code.gs`
3. บันทึก เลือกฟังก์ชัน `prepareProduction` แล้วกด “เรียกใช้” หนึ่งครั้ง จากนั้นอนุญาตสิทธิ์ Google Sheets/Drive ให้ครบ
4. กรอกรหัสผ่านชั่วคราวที่ไม่ซ้ำกันในคอลัมน์ `NewPassword` ของ `ParentAccounts` และ `TeacherAccounts`
5. เลือกฟังก์ชัน `applyPendingPasswordChanges` แล้วกด “เรียกใช้” ระบบจะเก็บเฉพาะ SHA-256 และล้างรหัสผ่านตัวจริงออกจากชีต
6. เลือก Deploy → Manage deployments → Edit → New version
7. ตั้ง Execute as เป็น Me และกำหนดสิทธิ์เข้าถึง Web app ให้ตรงกับผู้ใช้งานของศูนย์ แล้วกด Deploy
8. ตรวจว่า Web app URL ที่ลงท้ายด้วย `/exec` ตรงกับ `sheetApiUrl` ใน `config.js`
9. เผยแพร่ไฟล์หน้าเว็บผ่าน HTTPS ห้ามใช้ `file://` สำหรับการใช้งานจริง

เมื่อแก้ `Code.gs` หลังจาก Deploy แล้ว ให้เลือก Deploy → Manage deployments → Edit → New version เพื่อให้ Web app ใช้โค้ดรุ่นล่าสุด

> หน้าเว็บไม่มีโหมดล็อกอินสำรอง หาก Google Apps Script ใช้งานไม่ได้ ระบบจะไม่เปิดเผยข้อมูลเด็กและจะไม่บันทึกข้อมูลไว้เฉพาะเครื่อง

## ความปลอดภัยก่อนเปิดใช้

- ห้ามอัปโหลด `student-details.js` และ `photo-map.js`
- ห้ามตั้ง Spreadsheet เป็น “Anyone with the link”
- ใช้รหัสผ่านเฉพาะบุคคลอย่างน้อย 6 ตัวอักษร และเปลี่ยนทันทีเมื่อสงสัยว่ารั่วไหล
- การลองรหัสผิด 5 ครั้งจะถูกพักบัญชีชั่วคราว 15 นาที
- การอ่านข้อมูลส่วนตัวและการเขียนทุกชนิดต้องใช้ session ที่ออกหลังเข้าสู่ระบบ
- รหัสผ่านและ session ถูกส่งด้วย POST ไม่ปรากฏใน URL
- Deploy Google Apps Script รุ่นใหม่ทุกครั้งหลังแก้ `Code.gs`

## รูปเด็กและครูจาก Google Drive

ตัวเชื่อมจะอ่านชื่อเต็มจาก Google Sheets และจับคู่กับชื่อไฟล์ภาพในโฟลเดอร์ Drive โดยอัตโนมัติ:

- เด็กเตรียมอนุบาล 1/1: `เตรียม 1/เตรียม 1`
- เด็กเตรียมอนุบาล 1/2: `เตรียม 2/เตรียม 2`
- เด็กอนุบาล 1: `อนุบาล1/อนุบาล1`
- ครูและบุคลากร: `ครู/ครู`

ไฟล์ภาพต้องมีชื่อเต็มตรงกับคอลัมน์ “ชื่อ - สกุล” ในชีต ระบบไม่พึ่งลำดับเลขหน้าชื่อไฟล์และรองรับช่องว่างที่ไม่เท่ากัน หากตั้งโฟลเดอร์เป็น “ทุกคนที่มีลิงก์” รูปจะเปิดจากหน้าเว็บได้โดยไม่ต้องลงชื่อเข้าใช้ Google

ไม่ควรเปลี่ยน Spreadsheet เป็น “Anyone with the link” เพราะภายในไฟล์มีข้อมูลส่วนบุคคลของเด็กและผู้ปกครอง
